# 💻 AI Code Assistant

An AI-powered Code Assistant built using Streamlit and Google Gemini API.

## Features

- Generate Code
- Explain Code
- Debug Code
- Optimize Code
- Add Comments
- Convert Programming Languages

## Tech Stack

- Python
- Streamlit
- Google Gemini API

## Installation

```bash
pip install -r requirements.txt
```

Create a `.env`

```
GEMINI_API_KEY=YOUR_API_KEY
```

Run

```bash
streamlit run app.py
```
